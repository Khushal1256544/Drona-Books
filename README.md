# 📚 Drona Books – Online Bookstore

Drona Books is an online bookstore web application featuring engineering, computer science, and MBA books across 10 categories.

## ✨ Features

- 🎬 Animated landing page
- 📚 Browse books by category
- 🛒 Add books to cart and remove them
- 🔐 Demo login and guest mode
- 📖 Collection of 60 books

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
